## 0.3.0 新增功能

- 默认开启深度思考与联网搜索（模型支持时生效）。搜索工具返回的查询词、读取网址和完成状态在消息中显示，并随消息同步。模型不检索时不会虚构搜索词。
- 每个会话独立生成，最多同时运行 4 个。可切换会话、新建会话、单独停止；收到的输出保存到对应对话。草稿分别保留在当前运行的各会话中。
- 浅色/深色/系统主题、玻璃界面、12–36px 消息字体大小，字体名称与字体文件导入，可在“设置 → 字体设置”中选择。字体页支持任意本机字体名称（可用英文逗号指定后备字体）、TTF/OTF/WOFF/WOFF2 文件（≤32 MiB）、12–36px 字号、聊天区域/整个应用范围、代码块开关和实时预览。字体文件仅保存于本机字体库，重启后自动加载，不随消息同步。
- **TTS 使用 Edge TTS，完全不调用 DeepSeek TTS。** 点击消息“朗读”，支持普通话、粤语、台湾国语和英语声音及语速调整；长消息分段播放，可随时停止。文字发送至微软语音服务，无需 DeepSeek Key。该服务无本应用可保证的长期协议和可用性承诺。
- 图片输入：每条最多 4 张，通过图片按钮或粘贴添加，最长边压缩至 1400px。图片作为消息附件保存在手机并加密同步。DeepSeek Flash 使用视觉接口；不支持图片的模型不会收到历史图像内容，只收到文件名说明。分享链接仍仅导入文字。
- 语音转文字：支持前台录音（需授予麦克风权限，最长 119 秒）与音频文件输入（最长 120 秒）。本地转换为 16kHz 单声道 PCM16 WAV 后，发送给当前模型提供方；识别结果放入草稿供编辑。DeepSeek ASR 与自定义提供方 ASR 可能收费，遵循对应服务标准。
- 手动添加 OpenAI Chat Completions 兼容提供方，分别设置地址、Key、模型 ID、上下文窗口、输出上限、视觉/搜索能力、思考参数和 ASR 模型。远程 API 须使用 HTTPS，本机回环可使用 HTTP。各家的工具协议不统一，搜索选项仅适用于兼容 DeepSeek 搜索工具的服务。
- Windows/Android 使用原生剪贴板；代码下载在 Windows 选择路径，Android 10+ 保存至下载目录，旧版 Android 使用系统保存文件界面。出于隐私，Android 读取剪贴板需在应用前台主动操作。

原文、图片和查询词随聊天同步；提供方 API Key、代理、外观和声音设置只存本机。两端均应更新至 0.3.0 后再使用图片同步。

## 长对话、流式回复与上下文

- 历史消息每页显示 12 条，可通过“更早消息 / 更新消息 / 回到最新”浏览全部原文。完整 Markdown 在 Web Worker 解析并缓存，思考过程仅在展开时加载；不再把长消息降为纯文本。流式回复支持实时 Markdown、GFM 表格/任务列表/删除线、数学公式、HTML 安全过滤，以及带语言名称的代码块复制和下载。输入改为单一 Markdown 编辑区，原文与样式在同一位置显示：标题、粗体、斜体、删除线、引用、链接和代码直接呈现样式，语法标记极淡显示。没有独立预览面板；发送内容保留原始 Markdown。
- 分享与 JSON 导入在 Web Worker 中解析，修正长批量导入时反复扫描全库生成修订号的开销，以及导入时间戳落到未来而影响后续消息顺序的问题。
- 回复和思考通过原生 SSE 增量传回，界面合并刷新。可点击发送位置的“停止生成”按钮；停止或网络中断时保留已收到的内容。流式内容在生成结束或停止后写入聊天库并同步，不逐 token 重写手机存储。
- 默认开启上下文自动压缩，达到接近 1M 总窗口时，较早历史分批生成摘要，最近的完整消息保留原文。摘要缓存在聊天中并随手机同步，原始记录不会删除。
- 当前模型窗口为 1,048,576 tokens，包含输入与输出。因此正常聊天为 24,576 输出 tokens 和 4,096 协议开销预留空间，输入阈值为 1,019,904 tokens，不能等输入本身达到 1M 后再额外生成 24K。以 [DeepSeek 模型元数据](https://api-docs.deepseek.com/api/list-models/) 为准。
- token 初始采用字符估算（英文约 0.3 token/字符、中文约 0.6 token/字符）；普通非联网对话收到接口实际 `prompt_tokens` 后，会对已发送前缀的用量进行校准，后续新增消息继续估算。联网请求的用量可能汇总多个内部步骤，因此不用于该校准。若接口明确返回上下文已满，会在未输出内容时压缩后重试一次。估算仍有误差，实际计数以 [DeepSeek 用量](https://api-docs.deepseek.com/quick_start/token_usage/) 为准。
- 摘要会调用 DeepSeek API 并产生额外用量；第一次压缩极长历史可能需要等待。每批新增资料约最多 24,000 个估算 tokens，再与已有摘要合并。摘要可能遗漏信息，重要细节应参考原文。最新单条消息本身过长、无法保留摘要与回复空间时会明确提示拆分，不会悄悄截断。较早消息修订变化后，对应摘要会失效并重新生成。
- 新版设备协商后按记录修订号交换差异，空闲时不再反复传输整库正文。界面读取也携带版本号，记录未变时只更新状态。首次同步仍需传输完整记录，旧版设备可继续使用原协议。

## 使用

1. 安装 Android APK，在“设置”中填写 DeepSeek API Key。手机可以独立聊天。
2. 手机打开“设备同步”，选择“服务器加密转发”，手动填写管理员提供的服务地址，记录配对密钥并开启同步。允许通知，并按手机系统要求允许后台运行、自启动；若需要长时间待机同步，请允许应用不受电池优化限制。持续同步会增加耗电。
3. 打开 Windows 程序，在“设备同步”里选择相同服务地址和转发模式，将**手机**的配对密钥填入电脑并开启同步。电脑若要直接调用模型，也需填入自己的 API Key，可以与手机使用同一个 Key。
4. 两端在线且网络可达时，电脑约每 20 秒与手机同步，电脑生成新消息也会尝试立即同步。电脑断线后可在本次运行内继续对话，恢复连接后补同步。
5. 手机消息在应用私有目录加密保存；Windows 正常运行不将聊天库写入文件。退出时若仍有未同步消息，会要求选择返回同步或放弃消息。手动导出备份会按用户操作产生含聊天文字的 JSON 文件，请自行保管。

联网搜索使用 DeepSeek 官方的 `deepseek_web_search` 和 `deepseek_read_url` 服务端工具，同一个 API Key 即可使用，不需要第三方搜索账号。选择“联网搜索”表示允许模型按需检索，不代表每次回答必定发起搜索。联网模式推荐 `deepseek-flash`；如当前账号或模型不支持，请根据 API 的报错调整模型。联网搜索与推理可能单独计费，以 [DeepSeek 文档](https://api-docs.deepseek.com/guides/web_tools/) 为准。

“导入分享”接受 `https://chat.deepseek.com/share/…`，读取公开分享接口，将用户/助手文字及可用思考内容导入为新对话，之后可以继续提问。不携带网页登录 Cookie，不访问私人会话。网页接口没有本项目可依赖的稳定公开契约：链接过期、访问限制、接口或结构变化可能导致失败。也支持导入本软件导出的 JSON 备份。

## 服务器转发与 IPv6 直连

默认使用服务器转发：两端主动连接同一个 HTTPS/WSS 地址，无需填写手机 IP，也不要求设备有公网 IPv6。IP 或网络变化后会在心跳检测到断连后自动重连（通常几十秒），服务器转发密文分片，没有聊天数据库、离线消息队列或正文日志。服务器重启会断开连接；两端自动重连，并按记录修订号补同步。手机不在线时不能从服务器取回历史，电脑未确认同步的消息仍只在内存，退出前必须同步到手机。

配对密钥在端侧用于 AES-256-GCM 加解密；连接服务器时只发送由密钥派生的不可猜测路由标识，不发送配对密钥或 API Key。服务器仍可看到网络连接、时间、路由标识和流量大小。HTTP/WebSocket 连接还受 HTTPS 证书保护。服务器代码在 `server/relay.cjs`，仅占用现有服务器，不依赖额外云产品。

仍可手动选择 IPv6 直连；以下条件只适用于直连模式：

- 手机必须拥有电脑可访问的 IPv6 地址，且手机网络、运营商和路由器允许该端口的入站 TCP。存在公网 IPv6 地址并不等于入站可达；部分蜂窝网络会阻止入站连接。
- 同一局域网的 ULA 地址也可使用；`fe80::` 链路本地地址需要接口作用域，本版本不支持。手机地址变化后需在电脑更新。
- 手机后台服务持续运行；系统强行停止应用、限制后台或手机关机时无法同步。已经启用同步的手机会尝试在重新开机后恢复服务，实际受系统自启动政策限制。
- 直连模式不会悄悄改用服务器。要通过服务器同步，需在两端明确选择服务器加密转发。
- 配对密钥允许读写全部同步聊天。只通过可信渠道传递。更换密钥后需要重新配置所有电脑。
- 协议采用应用层 AES-256-GCM 信封加密。底层 HTTP 只承载密文；具有 5 分钟时间窗口和请求 ID 重放检测。两端系统时间应准确。连接元数据（IP、流量大小、时间）不被隐藏。

手机为持久存储端，但同时编辑不同设备的记录会按记录修订号合并；删除保留墓碑，避免重连恢复已删除消息。删除也会传播到手机。为避免误删来源，当前版本不提供批量清空或墓碑压缩。

## 数据与凭据

- Android 使用 Android Keystore 中的 AES 密钥加密本地聊天库与设置；关闭系统自动备份，提供手动明文 JSON 备份。
- Windows 使用 Electron `safeStorage`（Windows 系统保护）保存 API Key、配对地址和密钥；聊天记录仅保存在进程内存。操作系统交换文件、崩溃转储或外部截图不在“不主动保存聊天库”的保证范围内。
- 卸载手机应用可能永久删除聊天和 Keystore 密钥。卸载前请手动导出备份。
- API、分享、Edge TTS、ASR 与远程图片请求支持显式本机 HTTP 代理，设置代理后连接失败不会回退直连。Windows 还会读取进程的 `HTTPS_PROXY` / `HTTP_PROXY`。Android 空代理设置表示使用应用直接连接。设备间 IPv6 同步按设计直接连接对端。

## 开发与构建

需要 Node.js 22+、JDK 21+、Android SDK 35（含 Build Tools 34 或由 Gradle 安装），以及 Windows。前端 React + TypeScript + Vite；Windows Electron；Android Capacitor + Java 原生持久化与同步服务。

```powershell
$env:HTTP_PROXY='http://127.0.0.1:7897'
$env:HTTPS_PROXY=$env:HTTP_PROXY
$env:ALL_PROXY=$env:HTTP_PROXY
$env:NO_PROXY='localhost,127.0.0.1,::1'
$env:ELECTRON_GET_USE_PROXY='1'
$env:GLOBAL_AGENT_HTTP_PROXY=$env:HTTP_PROXY
npm install
npm test
npm run desktop
npm run pack:win
npm run android:sync
```

Android 构建还需设置本机 `JAVA_HOME`、`ANDROID_HOME`。Gradle 不一定读取代理环境变量，需在构建进程设置 Java 代理（不要将个人路径或代理凭据写入项目）：

```powershell
$env:JAVA_TOOL_OPTIONS='-Dhttp.proxyHost=127.0.0.1 -Dhttp.proxyPort=7897 -Dhttps.proxyHost=127.0.0.1 -Dhttps.proxyPort=7897 -Dhttp.nonProxyHosts=localhost|127.*|[::1]'
.\android\gradlew.bat -p android --no-daemon assembleDebug
```

`npm run pack:win` 使用已安装的 Electron 二进制。若 Electron 安装脚本下载失败，应排查代理或通过同一代理下载对应官方 Electron 发行包，不能回退外网直连。

可用 `npx electron scripts/verify-ui.cjs` 检查 Windows 欢迎页、设置和手机布局，测试配置和截图位于被忽略的 `.local`。额外的 Java/Node 互通测试需要将 Maven Central 的 `org.json:json:20240303` JAR 放在 `tools/json-20240303.jar`，然后执行 `npm test`；缺少该 JAR 时会明确跳过这一项。

## 当前版本边界

- 聊天库大小上限约 64 MiB，适用于个人的少量设备；超过限制需要管理记录和备份。删除墓碑会保留，并继续计入大小。
- 分享导入支持文字，不导入原网页文件、图片和完整搜索过程。
- 当前测试 APK 使用开发签名，Windows 程序没有商业代码签名；不适合作为商店正式发行包。
- 没有真实 API Key 时只能完成接口结构、错误处理和本地测试，不能宣称实际付费推理/搜索已验证。跨运营商连通性与 Android 后台策略仍需在实际手机上验证。

新版额外验证：`npx electron scripts/verify-upgrade.cjs` 检查双会话并行、独立停止、实时 Markdown、草稿预览、代码复制/下载、图片与检索记录保存、默认思考/搜索及深色设置。收费模型/ASR 采用模拟接口；Edge TTS 已通过本机代理实际返回 MP3。当前没有连接 Android 真机，麦克风、扬声器、厂商剪贴板限制仍需在实际手机上验证。

0.3.0 同版本更新：新增独立字体页面，并统一深浅色控件、卡片圆角、按钮、开关与滑块配色。可运行 `npx electron scripts/verify-fonts.cjs` 验证任意字体名称、文件导入、无效文件拒绝、预览、保存/重启恢复、手机布局以及原有凭据保持。


0.3.0 同版本编辑器更新：合并输入和样式预览，保留淡色语法标记，支持撤销、光标处粘贴、中文输入法及移动端换行。`npx electron scripts/verify-editor.cjs` 验证单一编辑区、格式样式、淡色标记、光标粘贴、撤销、输入法 Enter、原始 Markdown 发送和深浅色/手机布局。

服务器转发验证：`npm test` 检查密文分片、配对隔离、双向合并、离线处理与重新连接。设置 `JAVA_HOME` 后运行 `node scripts/verify-relay-java.cjs`，可以用 Android 的实际 Java RelayAgent 与 Windows Node 客户端经过真实 HTTPS 服务验证大消息、增量与重连；测试使用独立随机配对标识和合成数据。

Windows 本地开发与打包需要 Visual Studio C++ Build Tools（桌面 C++ 工作负载）及 Windows 10 SDK；运行 `npm run build:native` 生成原生合成辅助库。`npm run desktop` 与 `npm run pack:win` 会自动执行此步骤。普通用户使用发行包无需安装构建工具。
